# Browny Date Widget

Live date + time tile for iPhone.

Open: https://nbrowny3108.github.io/browny/

Shows weekday, full month name, day number, month number, year, week number, and AEST time.

## Add to Home Screen (Safari)

1. Open the link in Safari (not Chrome).
2. Tap Share → Add to Home Screen.
3. Name it **Browny**.

The home-screen icon is a calendar tile. The page itself is the live widget (icons on iOS do not update by themselves).

## Real updating Home Screen widget (Scriptable)

1. Install **Scriptable** from the App Store (free).
2. New script → paste `Scriptable-Browny-Date.js`.
3. Long-press Home Screen → + → Scriptable → this script → Small.

This is the version that updates on the Home Screen every day.
